# Figma2Klaviyo — responsive email HTML export

Turn a supported Auto Layout email frame into editable, responsive HTML for Klaviyo.

Start free: select a frame, export, preview, and download the HTML. No account, checkout or API key needed for local exports. Supports 40 visible nodes, plain text, solid fills, horizontal/vertical layouts and your own hosted HTTPS images. Email columns stack on narrow screens.

Import the downloaded file into a Klaviyo custom HTML template. This produces code-based templates, not drag-and-drop blocks. Fonts are normalized to email-safe Arial/Helvetica. Vectors, mixed text styles, absolute positioning, masks, effects and gradients are unsupported. Check sender address and email-client rendering before sending.

Optional server upload requires your own Klaviyo account, self-hosted server and operator-issued Paddle-verified license. That integration is not a currently purchasable hosted service; no checkout is active. No private Klaviyo or Paddle key is entered in the plugin. The plugin asks before transferring a design. It never sends campaigns.
